# 复述训练场

每天一张高质量内容卡 → 开口复述 → AI 当听众追问 → 收尾报告 + 词库沉淀。

## 启动

```bash
npm install
# 复制 .env.example 为 .env，填入 LLM_API_KEY（DeepSeek 等 OpenAI 兼容接口）
npm start
```

打开 http://localhost:3025 （默认端口 3025，可在 .env 改 PORT）。

> 没有配置 .env 时服务也能启动，但练习页的 AI 追问会提示"请检查 LLM 配置"。

## 导入 EPUB 图书

进入「读书」页面后，可以直接选择一个或多个 `.epub` 文件，也可以选择整个文件夹批量导入其中的 EPUB。导入后的文件保存在项目的 `data/books` 本地目录中，无需再配置固定的外部书籍目录。

## 面试刷题

顶部菜单新增「面试刷题」，内置「企业真题」和「面试题库」两类题目（共 2580 道）。企业真题先按公司定位，面试题库先按模块定位；进入范围后可浏览全部题目，再从本范围随机抽题，开始 3 分钟作答。提交后会结合参考答案生成总结，再复述一次即可保存完整记录。题库快照位于 `interview-bank/`；如需改用其他目录，可在 `.env` 设置 `INTERVIEW_BANK_DIR`，目录下保持 `面试题库/` 和 `企业真题/` 两个子目录即可。

## 使用流程

1. 卡片库页：手动添加一张卡，或用"AI 按主题生成"
2. 首页点"开始练习" → 读卡 → 点"开始复述"用语音转写（或直接打字）→ "讲完了"
3. AI 听众追问漏掉的要点，直到说清楚（最多 6 轮）
4. 收尾报告：要点总结 + 用词反馈，替换词自动进词库
5. 词库页、历史页随时回看

## 内容供给（两个现成入口）

- **内置 10 张经典卡**：项目已自带种子卡片（愚公移山、塞翁失马、田忌赛马、背影节选等，公共领域）。清库后想恢复：
  ```bash
  node seed_cards.js
  ```
- **一键抓料**（从 RSS 抓摘要/正文 → 必要时补抓文章页 → AI 筛选 → 英文转中文 → 清除网址等网页噪声并重新分段 → 自动入库）：
  ```bash
  node --env-file-if-exists=.env fetch_cards.js            # 抓取并入库
  node --env-file-if-exists=.env fetch_cards.js --dry-run  # 只看筛选结果
  ```
  「素材库 → 订阅素材」可以手动立即抓取、重新整理已有素材并查看来源健康状态；服务启动 5 分钟后会自动抓一次，此后每天一次。每篇素材独立保存并显示源站文章日期（与入库时间分开）。英文素材会自动翻译为自然中文，去除网址、署名、订阅/评论提示等无关信息，并整理成适合复述的短段落。当前接入少数派、美团技术团队、MIT News、NASA、Ars Technica 和阮一峰。BBC 已保留配置，但因当前 Node 运行环境 TLS 连接不稳定而默认停用。源在 `fetch_cards.js` 顶部的 `FEEDS` 里增删；长期使用建议自建 RSSHub（`docker run -p 1200:1200 diygod/rsshub`）并启用 `localhost:1200` 的路由。未配置 Key 时只执行本地清洗，无法完成英文翻译。
